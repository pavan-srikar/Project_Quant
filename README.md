# Project_Quant

An open-source TradingView alternative with a quant-grade backtest engine and algo trading engine. This is some advance quant shit with all the tools quants and hedge funds use (Monte Carlo simulations, Efficient Frontier, strategy testing, and automated trade execution for strategies you code and lota other stuff) into one place.

> made by pavan_srikar.

## How to Run

```bash
npm install && npm run dev
```

Open `http://localhost:5173` in your browser (requires Node.js 18+).
